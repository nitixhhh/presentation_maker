# Design principles (the rules every slide follows)

## 1. One idea per slide
- Each slide answers one question. The title or key message states the answer.
- Glance test: a viewer should get the point in about 3 seconds. If they would have to read
  everything to find the point, the hierarchy is wrong.
- If you need "and" to describe the slide's point, it may be two slides — tell the planner
  via your notes, but on this slide keep the strongest idea and cut the rest.

Example: title "Black holes bend light so strongly that nothing escapes" beats "Black holes".
(Action titles: a full short sentence with the takeaway, common in consulting decks. Use them
on content slides; keep topic-style titles for title, section and agenda slides.)

## 2. Hierarchy: the eye needs an order
Make three levels, clearly different:
1. Primary — the key message or the main visual (largest, highest contrast, most space).
2. Secondary — the supporting points or labels.
3. Tertiary — sources, captions, slide number (small, muted).
Tools for hierarchy: size (step at least 1.3× between levels), weight, colour (accent only
on the most important thing), position (top-left is read first in left-to-right languages),
and space around an element.
Don't: make everything bold, or give three things the accent colour.

## 3. Whitespace is a design element
- Leave margins: at least 56 px from the edges for text; 80 px left/right reads more premium.
- Gaps between groups (24–48 px) larger than gaps inside a group (8–16 px). Related things
  sit close; unrelated things sit apart (proximity).
- Empty space should look intentional: a calm side for the title, breathing room around
  a number. Big dead areas (a half-empty slide) look unfinished — fill with the main visual.
- Target: content covers roughly 45–75 % of the canvas.

## 4. Alignment grid
- Use a 12-column mental grid on 1280 px: 80 px outer margins, 1120 px content width,
  columns ~70 px with 24 px gutters. Useful splits: 6/6, 7/5, 8/4, 4/4/4, 3/3/3/3.
- Vertical rhythm: title band ~64–160 px from top, content from ~200 px, footer zone below 660 px.
- Every element's edge lines up with something else (a column edge or another element).
  Pick left-aligned text for anything longer than one line; centre only short titles,
  quotes and single numbers.
- Equal items get equal sizes (three cards = three equal widths and heights).

## 5. Consistency across the deck
- Same title position, size and style on all content slides.
- Same palette, fonts, motif, corner radius, icon style and shadow style everywhere.
- Slide numbers and footers (if used) in the same place every time.
- But vary the composition: no layout more than twice in a deck, and never the same
  layout on two neighbouring slides.

## 6. Contrast and emphasis
- Make different things clearly different (size, colour, weight) and same things identical.
- One focal point per slide. The accent colour marks it.
- Text must be readable from the back of a classroom: see typography-colour.md.

## 7. Text limits

| Thing | Limit |
|---|---|
| Title | ≤ 10 words, 1–2 lines |
| Key message | ≤ 20 words, ≤ 2 lines |
| Points on a content slide | 3–4 (max 5 in a table or agenda) |
| One point | ≤ 15 words; fragments without full stops |
| Body words on a slide | ≤ 55 (hard checker limit 120 in total) |
| Line length | 35–60 characters (set box widths so lines wrap there) |
| Diagram / icon labels | 1–4 words title, ≤ 8 words description |
| Lines per text block | ≤ 4 |

If the content does not fit at minimum sizes, cut words. The speaker notes carry the detail.

## 8. Show, don't list
- Replace bullet lists with structure when the content has structure: steps → process,
  categories → cards with icons, numbers → big numbers or chart, A vs B → comparison.
- Plain bullets are acceptable only for short, truly unordered items, and still with
  clear hierarchy and spacing.

## 9. Signal over noise
- Every element must earn its place: it either carries information or guides the eye.
- Remove: decorative clip-art, extra borders, shadows on everything, gradients behind text,
  logos on every slide, repeated titles inside the slide, "Introduction:" prefixes.
- Decorative shapes are allowed only as quiet background (motif, thin rule) — never decorative slide
  numbers or giant numerals ("04"); the engine removes them,
  never on top of text and never competing with the main visual.

## 10. Truth
- Only facts, numbers, names and sources from the brief. No invented statistics, dates,
  quotes, emails, URLs or people.
- A number that matters gets its source marker `<sup>[n]</sup>`.
- If something is missing, design around it (use a word or diagram instead) — never fill.
